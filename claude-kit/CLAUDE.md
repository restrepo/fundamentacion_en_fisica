# claude-kit

Las instrucciones para Claude Code están en `instructions.md`, en la raíz del
repositorio. Claude Code las carga automáticamente a través de `CLAUDE.md`
(`@instructions.md`).

En esta carpeta:
- `skills/`: skills canónicas `leccion-a-deck`, `actualizar-repositorio` y `google-form-popup`.
- `latex/`: fragmentos pendientes de pegar en `main.tex` del libro.
